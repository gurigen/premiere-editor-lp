プレミアエディター LP 5月赤黒版 + 7月宇宙演出 統合版
========================================================

【いちばん簡単な確認方法】

1. ZIPを展開します。
2. start-preview.bat をダブルクリックします。
3. ブラウザで http://127.0.0.1:4178/ が開きます。
4. 読み込み直後の自動ワープが終わると、赤黒デザインのLPが表示されます。

【start-preview.bat が動かない場合】

このLPはES Modulesを使用しているため、index.htmlの直接ダブルクリックではなく、
Visual Studio CodeのLive Serverなど、ローカルWebサーバー経由で開いてください。

Pythonが入っている場合は、このフォルダーで次を実行できます。

  python -m http.server 4178

その後、ブラウザで http://127.0.0.1:4178/ を開きます。

【統合内容】

- 5月版の赤黒シックなレイアウトと本文を採用
- ページ読込直後、自動でワームホールへ突入
- 3本の3Dタイムラインレールは削除
- 宇宙背景はスクロールに合わせて前進
- 上部の00:00 / 00:12 / 00:24…と再生バーがスクロールに同期

公開する場合は、フォルダー内の構成を崩さず、Webサーバーへアップロードしてください。
