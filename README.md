# プレエディ LP

更新日: 2026-09-02

## 目的

VTuber・配信者向けのエンタメ動画編集を学ぶオンラインスクール「プレエディ」の公開LPです。

旧版の赤黒シックな編集画面モチーフと、読み込み直後のワープ・宇宙背景・スクロール前進演出を残しながら、実際に販売予定の商品内容へ全面的に更新しています。

- 総カリキュラム10時間超
  - 解説・実践講義: 約7時間30分
  - ノーカット編集実演: 2時間30分以上

- 通常価格198,000円、第1期先着20名は98,000円
- 第1期20名は卒業生限定の案件獲得コミュニティへ永久無料で参加可能
- LINE登録で無料5大特典

## ビジュアルと操作

- 読み込み直後に約3.65秒のワープを自動再生
- 宇宙背景の中を、スクロールに合わせて前進
- 上部のタイムコードバーをスクロール位置と同期
- 旧版にあった3本の3Dタイムラインレールは不使用
- クリックスchの立ち絵はファーストビューには出さず、講師欄だけで使用
- 「期待の声」は、foriioの人物カードを参考に、大きな画像・本文・氏名を一枚のカードへ整理
- 画像はWebPへ最適化し、ファーストビュー以外は遅延読み込み
- Q&Aはキーボード操作と支援技術向けの関連付けに対応
- 動きを減らす設定では、ワープと背景アニメーションを停止

## 主なファイル

- `index.html`: LP本文・商品情報・3名の期待の声・Q&A
- `styles.css`: 赤黒レイアウト、レスポンシブ表示、カードとタイムコードUI
- `scripts.js`: 目次同期、Q&A開閉、表示フォールバック
- `js/cinematic-background.js`: ワープ後の宇宙背景とスクロール連動
- `js/warp.js`: ワープ用シェーダー
- `lib/three.module.min.js`: ローカル同梱のThree.js
- `assets/voices/`: ナガレ様、キャメロン様、キルハ様の画像
- `docs/archive/2026-09-02-before-product-rewrite/`: 全面更新前の主要ファイル
- `output/qa-*.png`: 公開前のPC／スマホ確認画像
