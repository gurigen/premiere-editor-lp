# プレエディ LP

クリックスch監修のエンタメ動画編集スクール「プレエディ」の公式LPです。

## 現在の方針

- 以前の赤黒・動画編集画面ベースの構成を維持
- 読み込み直後の宇宙ワープ演出、スクロール連動の宇宙背景を維持
- 上部のタイムコード付きシーンレールを維持
- 冒頭のクリックス立ち絵だけを非表示化
- 実際の商品内容に合わせて文言、カリキュラム、価格、特典、Q&Aを更新
- 利用者の声はナガレ様、キャメロン様、キルハ様の3名を掲載

## 商品情報

- サービス名: プレエディ
- 受講形式: 録画教材を自分のペースで視聴
- 総カリキュラム: 10時間超
- 解説・実践講義: 約7時間30分
- ノーカット編集実演: 2時間30分以上
- 通常価格: 198,000円
- 第1期先着20名: 98,000円
- 第1期生: 案件獲得コミュニティ永久無料
- 添削: 月1〜2本程度を目安、厳密な回数上限は設けない予定

## ファイル

- `index.html`: LP本文
- `styles.css`: 赤黒のレイアウト、レスポンシブ表示、各セクションの演出
- `scripts.js`: シーン目次、カリキュラム、実績、利用者の声、Q&Aの操作
- `js/cinematic-background.js`: 宇宙背景とスクロール連動
- `js/warp.js`: 冒頭のワープ演出
- `assets/`: ロゴ、講師、作品、利用者の声の画像
